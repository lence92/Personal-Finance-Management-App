# Personal Finances icon set

Editable SVG icons created to match the supplied registration-page design.

## Included

- `brand-leaf.svg`
- `income-bars.svg`
- `wallet.svg`
- `spending-trend.svg`
- `eye.svg`
- `lock.svg`
- `trend-up.svg`

All icons use a `24 × 24` viewBox and inherit their color through `currentColor`.

## Angular usage

Copy the SVG files into `src/assets/icons/`, then use them as image assets:

```html
<img src="assets/icons/wallet.svg" alt="" width="24" height="24" />
```

For direct CSS color control, paste the SVG markup into a small standalone icon component and set `color` on the host element.
